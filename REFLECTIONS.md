# Group Project Reflection – Iris Dataset Analysis

### Challenges Encountered

We faced a few challenges with Python loops, reading and writing CSV files, and using GitHub to manage our work. Some parts of the code needed troubleshooting, and we had to make sure our data was cleaned correctly before analyzing it. We worked through these challenges by testing our code, fixing errors, and reviewing our results. We also learned to be more careful when updating shared files on GitHub.

### Group Dynamics

Working together allowed us to split the project into smaller tasks and focus on different areas. Everyone contributed to the project, from writing Python code and cleaning data to creating visualizations and building predictive models. We worked independently on our assigned parts while keeping each other updated. This helped us bring everything together for the final project.

### Lessons Learned

This project taught us the importance of communication, time management, and checking our work before combining it with others. We also gained more confidence using Python, working with datasets, and collaborating through GitHub. Moving forward, we'll focus on staying organized, communicating early, and giving ourselves enough time to review everything as a group before submitting.
